# 车辆尺寸与轴距精准选车工具及数据获取全景方案

本工具是一套专为“**根据车辆尺寸（长、宽、高）与轴距（Wheelbase）精准筛选匹配汽车**”而设计的高效开箱即用套件。

项目不仅包含直接在浏览器双击运行的现代化前端交互筛选应用，还打通了**真实在售车型数据抓取、车系聚合、清洗入库与离线持久化**的全流程。

---

## 一、 为什么采用“车系聚合 + 版本下钻”的双层交互？

在汽车配置中，同一款车系（如 Model 3 或 宝马3系）往往有 3 至 8 种不同的年款配置（后驱版、长续航版、高性能版、标轴与长轴版）。
- **如果每个版本单独作为一个卡片**：搜索结果会被同款车刷屏，用户无法快速扫视全行业车型分布；
- **车系聚合方案（本项目架构）**：
  - **外层（车系看板）**：每个车系只展示 1 个卡片，展示该车系的**尺寸变化区间（如 4720～4724mm）、轴距区间、空间得房率指标、指导价区间与在售版本数**；
  - **内层（配置下钻抽屉）**：点击卡片滑出侧边抽屉（Drawer），不仅清晰列出各具体版本的长宽、轴距、整备质量与价格对照表，还带有**车身俯视轮廓在标准车位（5.3m × 2.5m）中的 2D 投影透视图**！

## 二、 核心功能与交互设计亮点

直接在本地双击打开 [`index.html`](file:///c:/Users/320327744/Documents/antigravity/blissful-lovelace/car_dimension_filter/index.html) 即可体验：

1. **4 维度无级双滑块区间控制**：
   - 轴距区间：2300 至 3500 mm（核心空间指标，高亮醒目）
   - 车长区间：3400 至 5400 mm
   - 车宽区间：1500 至 2100 mm
   - 车高区间：1400 至 2100 mm
2. **空间得房率（轴长比 = 轴距 / 车长）指标体系**：
   - 原生纯电平台通常 ≥ 60%（短前悬长轴距，车内纵向空间大）；
   - 传统燃油长机头平台通常在 56% 至 59%；
   - 支持设置“最低得房率”阈值进行精准过滤。
3. **车位实用场景一键预设**：
   - 🅿️ **老旧/机械立体车位**：长 ≤ 4800mm，宽 ≤ 1850mm，高 ≤ 1550mm（完美避开限宽限高陷阱）；
   - 🛋️ **黄金空间大五座**：轴距 ≥ 2850mm，车宽 ≥ 1880mm（注重后排腿部横向空间）；
   - ⚡ **灵巧好开市区代步**：长 ≤ 4550mm，宽 ≤ 1830mm（穿梭自如好掉头）；
   - 👑 **行政旗舰大车**：长 ≥ 5050mm，轴距 ≥ 3000mm（商务行政气场）。
4. **同车系下钻抽屉 (Drawer) 与 2D 俯视轮廓模拟**：
   - 点击任一车系，平滑滑出侧边详情抽屉；
   - 模拟在标准私家车位（5.3m × 2.5m）内的占位情况，标明前后车轴位置；
   - 对比各版本的长宽高细微差异（如带行李架或空悬导致的车高变化）。
5. **多车同屏尺寸 PK 模态框**：
   - 勾选 2 至 4 款车系，底部弹出对比控制栏；
   - 点击开启同屏对比，生成**轴距与车长条形图直观叠层对比**以及多车核心参数对照表。
6. **多维排序与数据导出**：
   - 支持按轴距、轴长比、车长、车宽正倒序实时重排；
   - 一键导出当前筛选结果为带 UTF-8 BOM 的 CSV 电子表格。

## 三、 数据获取调研与接口全景

### 1. 汽车之家 M 端纯净数据接口（本项目采用并实测通过）
* **接口规范**：`https://car.m.autohome.com.cn/ashx/car/GetModelConfigNew.ashx?seriesId={series_id}`
* **特性**：零鉴权门槛，无 Cookie 限制，**无 PC 端的字体混淆反爬**，明文 JSON 返回。
* **分级抓取链路**：
  1. 品牌列表：`https://car.autohome.com.cn/AsLeftMenu/As_LeftListNew.ashx?typeId=1&brandId=0&fctId=0&seriesId=0`
  2. 车系列表：`https://car.autohome.com.cn/AsLeftMenu/As_LeftListNew.ashx?typeId=1&brandId={brandId}&fctId=0&seriesId=0`
  3. 配置详情：`https://car.m.autohome.com.cn/ashx/car/GetModelConfigNew.ashx?seriesId={seriesId}`

### 2. 工信部新车准入公告数据库（开源全量）
* **GitHub 仓库**：`https://github.com/coolcat0125/TA-Analysis`
* **说明**：汇总工信部第 341 至 410 批新车准入公告，收录 4,494 款国产新能源汽车申报尺寸与质量。注意：工信部只管理国产/本土生产汽车，**不包含任何纯进口车**（如保时捷全系、雷克萨斯全系等均需通过汽车之家等媒体源获取）。

## 五、 本地运行与实车外观图服务（方案 2）

本项目支持两种运行模式：

### 模式 A：一键极速服务模式（推荐，自动获取汽车之家官方实车图）
双击项目根目录下或 `car_dimension_filter` 目录下的：
```text
start_server.bat
```
* **一键启动**：自动启动本地图片中转代理与高速 Web 服务；
* **本地访问网址**：`http://127.0.0.1:8080/`（在浏览器中打开）；
* **实时突破防盗链**：利用内置中转与无 Referer 机制，实时从汽车之家拉取白底/实车外观高清大图；
* **本地磁盘持久化缓存**：已浏览车型的外观图片会自动持久化存储在 `car_dimension_filter/.cache/images/`，再次访问时 0ms 闪电秒开，无需重复联网！

### 模式 B：纯静态离线模式（无需 Python 环境）
直接在系统文件资源管理器中双击打开：
```text
c:\Users\320327744\Documents\antigravity\blissful-lovelace\car_dimension_filter\index.html
```
* 纯静态单页架构，内嵌全量 1,692 款车系与 12,547 款配置规格；
* 在离线或无图环境下，卡片与详情抽屉会自动智能折叠图片槽位，无缝呈现紧凑工整的纯规格看板，零留白、无裂图。
